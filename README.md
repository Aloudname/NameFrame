## 前言

旧的框架并不好用。使用过程中发现其接口过于开放非常难用、组件间通信方式乱、初始化和管理方法完全暴露不好控制等等。这已经不是一般的问题了，必须要出重拳！艰难地品尝自己烹饪的东西后，决定回锅重炒，根据上一版应用过程中的问题，结合一些毕设过程中的实践心得，提出底层的设计思想，在此基础上重新开发。这次，我一定要成功口牙！嘻嘻！♪(^∇^*)
